# Frontend

Instrucciones de frontend del Sistema de Gestión Documental
(`frontend_gestion_documental/`, Next.js 16 + Tailwind CSS 4).

## Archivos

- `instructions.md`: reglas de implementación (App Router, rutas, datos, formularios).
- `design-system.md`: dirección visual, layout del panel y del portal, componentes.
- `color-palette.md`: tokens de color y colores de estado (radicado y vencimiento).
- `responsive-accessibility.md`: responsive (escritorio y celular) y accesibilidad.

## Fuentes

- F-02 §2.3 (usuarios), §5.1 (interfaces de usuario), RNF-003 y RNF-005.
- `frontend_gestion_documental/app/globals.css` (tokens de Tailwind 4).
- `frontend_gestion_documental/node_modules/next/dist/docs/`.
